## 2. Sobre o projeto

O TechFlow é uma interface web para gerenciamento e acompanhamento de projetos, desenvolvida com o objetivo de organizar informações, facilitar a visualização de tarefas e centralizar o acompanhamento das atividades em um único ambiente.


## 3. Tecnologias utilizadas

* **JavaScript:** implementação das interações e validações da aplicação.
* **Tailwind CSS:** criação de layouts responsivos e estilização dos componentes.
* **Vite:** ferramenta utilizada para executar o ambiente de desenvolvimento e gerar a versão de produção.
* **Git e GitHub:** versionamento e hospedagem do código-fonte.
*HTML5:** estruturação da página e dos formulários.

## 4. Principais recursos implementados

* Dashboard para visualização geral dos projetos.
* Indicadores de projetos ativos, projetos concluídos, tarefas pendentes e equipes.
* Menu lateral para navegação entre as seções.
* Campo de pesquisa de projetos.
* Formulário para criação de projetos.
* Campos para nome, responsável, categoria, prioridade, prazo e descrição.
* Validação dos campos do formulário e mensagem de confirmação.
* Alternância entre tema claro, escuro e configuração do sistema.
* Menu de usuário com opções de perfil e configurações.
* Interface responsiva para diferentes tamanhos de tela.

## 6. Dificuldades encontradas

Durante o desenvolvimento do TechFlow, algumas das principais dificuldades foram a organização dos componentes da interface, a criação de um layout responsivo e a implementação das interações com JavaScript.

Também foi necessário trabalhar na validação dos dados inseridos nos formulários, na alternância entre os temas claro e escuro e na integração entre HTML, CSS e JavaScript.


## 7. Considerações finais

O desenvolvimento do TechFlow proporcionou a aplicação prática de conceitos de desenvolvimento web, permitindo construir uma interface de gerenciamento de projetos com foco em organização, usabilidade e responsividade.

O projeto também possibilitou aprimorar conhecimentos em HTML, CSS, JavaScript, Tailwind CSS, Vite e versionamento de código com Git e GitHub.
